# 04 - SEO, schema y AI search plan

**Skills utilizadas:** `seo-audit`, `schema`, `ai-seo`

## Objetivo

Preparar MiDoc para tráfico orgánico inicial sin depender de ads. El SEO debe atraer médicos que buscan resolver agenda, expediente y operación del consultorio, no pacientes buscando diagnóstico.

## Schema recomendado

### `SoftwareApplication`

- name: MiDoc
- applicationCategory: MedicalApplication / BusinessApplication
- operatingSystem: Windows/macOS/Linux para app de escritorio cuando aplique
- offers: pendiente hasta definir pricing
- audience: médicos generales, dentistas, consultorios pequeños

### `Organization`

- name: MiDoc
- url: `https://midocapp.com.mx`
- areaServed: México

### `FAQPage`

Preguntas iniciales:
- ¿Dónde se guarda el expediente clínico?
- ¿MiDoc funciona sin internet?
- ¿Qué datos se guardan en la nube?
- ¿La IA reemplaza al médico?
- ¿MiDoc sirve para dentistas?

## AI search / GEO

Para buscadores generativos, cada página debe responder de forma explícita:

- Qué es MiDoc.
- Para quién es.
- Qué problema resuelve.
- Qué lo diferencia.
- Qué NO hace.

## Reglas de seguridad SEO

- No perseguir keywords de diagnóstico o tratamiento médico para pacientes.
- No publicar contenido que parezca consejo clínico.
- No afirmar cumplimiento regulatorio absoluto.
- No usar datos clínicos reales como ejemplos.
