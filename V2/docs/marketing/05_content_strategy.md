## Reglas editoriales

- Escribir para médicos, no para pacientes buscando tratamiento.
- No dar indicaciones clínicas.
- No usar historias reales con datos identificables.
- Cada artículo debe enlazar a una página comercial y a privacidad/local-first.
- Cada claim técnico debe ser consistente con la arquitectura V2.
