## Restricciones no negociables

- No usar PHI en marketing, analítica, ejemplos ni campañas.
- No prometer diagnósticos, curas ni resultados clínicos.
- No presentar la IA como sustituto del criterio médico.
- No afirmar métricas, clientes o testimonios inexistentes.
- Priorizar confianza, privacidad y claridad sobre urgencia comercial agresiva.
